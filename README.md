# Sitebars

Веб-приложение с 5 экранами (Главная, О нас, Прайс, Админ-панель, Админ-панель 2) и динамической работой прайса через MySQL.

## Запуск

1. Поднимите MySQL и примените схему:
   ```bash
   mysql -u root -p < sql/schema.sql
   ```
2. Запустите PHP-сервер:
   ```bash
   php -S 0.0.0.0:8000 -t public
   ```
3. Откройте http://localhost:8000

## Переменные окружения

- `DB_HOST`, `DB_PORT`, `DB_NAME`, `DB_USER`, `DB_PASS`
- `VK_GROUP_ID`, `VK_TOKEN`, `VK_SUBSCRIBE_URL`
- `BARS_ADDRESS`, `BARS_PHONE`

## Авторизация админа

По умолчанию (из seed):
- login: `admin`
- password: `admin123`

## Что реализовано

- Оверлей записи + копирование телефона.
- Переходы по кнопкам и нижняя навигация.
- Динамический прайс с загрузкой из MySQL.
- Админка с добавлением категорий/услуг и переключением `от/фикс`.
- Сохранение изменений в `razdels` и `price`.
- Блок VK-постов (с реальным API VK по токену, иначе fallback).
- Блок отзывов (фильтр `rating >= 4`).
- Яндекс карта, геокод адреса, кнопка маршрута.
